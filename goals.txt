DONE detail for #15 (b30): vendored libFLAC + libogg (both BSD/Xiph, matches the
project's permissive-only policy) under vendored/flac + vendored/ogg. New
DEC_KIND_OGGFLAC in vendored/decoders/decoders.c; an Ogg FLAC file is now
decoded by libFLAC through the existing pcm_to_stereo path, so it gets the same
resampler/SEEK/END_OF_STREAM behaviour as WavPack and can play alongside Ogg
Vorbis in one queue. Fixtures: tools/fixtures/*.oga (8/16/24/32-bit, mono,
stereo, 5ch, 22.05/44.1/96 kHz) plus reference .oga files from the reference
`flac` CLI for cross-verification.

DONE detail for #16 (b31): Effects drawer tab with a 64-band log-spaced
spectrum, peak-hold caps, dBFS readout and decade axis labels. Hand-rolled
radix-2 FFT (src/Spectrum.swift) after vDSP's split-complex real FFT packing was
found to halve bin numbering; DSP split into a testable SpectrumCore.
tools/test_spectrum/main.swift compiles the production source and passes 52
checks (FFT vs naive DFT, tone->bin at 44.1/48/96 kHz, band mapping, level
scaling, ring wrap, stereo downmix). Found and fixed 3 real bugs: Float->Double
ring read after wrap, unnormalized magnitudes, and a -6 dBFS ceiling that
clipped ordinary material.

DONE detail for #21 (b32): metadata editor in the flyout's Utilities tab. Pure-Swift
ID3v2 reader/writer (src/AudioTags.swift, zero deps) reads v2.2/v2.3/v2.4 with
unsync, extended headers and APIC art, and writes v2.3 preserving every unmanaged
frame; src/TagEditor.swift renders the fields. Only ID3 containers (mp3/mp2/mp1/mpa)
are editable. tools/test_id3/main.swift compiles the shipping source and passes
46/46; the writer was independently cross-checked against a hand-written Python
ID3 parser on a real lame-encoded MP3.

DONE detail for #14 (b33): gapless + crossfade in the flyout's Effects tab.
A second confirm-on cadence AVAudioEngine is pre-started just before the
outgoing track ends (native format path only), so a transition needs no
teardown gap. Options: Off (the proven stop-then-start path, default), Gapless
(0.08 s overlap, incoming starts at full volume) and true crossfades of 2/4/6/8 s
(piecewise-linear node-volume ramps at 20 ms). src/Crossfade.swift holds the
option mapping and fade math as pure code; tools/test_crossfade/main.swift
compiles the shipping source and passes 34/34. Repeat-one, the last track with
repeat off, and the shuffled repeat-all wrap are deliberately left to the normal
end-of-track path (the wrap re-permutes the queue). Pause, seek and stop cancel
an in-flight transition.

DONE detail for #17 (b33): 10-band EQ in the Effects tab. The DSP is a single
AVAudioUnitEQ inserted between each in-app engine's main mixer and its output
node (native AVAudioFile, embedded AVAudioSourceNode, and MIDI sequencer paths),
so every track through those engines passes through the same live-adjustable
filters. The AVPlayer fallback and AVMIDIPlayer paths cannot host an AU insert
and stay flat (documented in the UI hint). Bands are the classic ten-slopers
31 Hz..16 kHz, 1 octave apart, Q 1.0, ±12 dB; gains/state persist (ac_eq_active,
ac_eq_gains). src/Equalizer.swift pairs the Equalizer state object with a
testable EqualizerCore: RBJ peaking-biquad coefficients + a unit-circle
frequency response. tools/test_equalizer/main.swift compiles the shipping source
and passes 24/24 (band table, clamping, guard rails, 0 dB identity across the
range, boost peaks at the target gain and returns to unity far away, cut is the
exact reciprocal of boost, clamped -12 dB floor, band 1 octave away is smaller).

UI / DRAWER DESIGN (agreed 2026-09-23, clean-UX principle):
- Main window must NOT grow crowded. Heavy/optional features live in ONE
  right-side OVERLAY drawer (Xcode/Inspector style - floats over the right
  pane, panes never reflow) with a segmented TAB BAR inside; each tab
  scrolls internally; one toggle opens/closes it.
- Proposed tabs: Library (playlists, format info), Effects (EQ, ReplayGain,
  visualizer), Utilities (sleep timer, metadata editor).
- Mini player = separate floating window; media keys = global; neither
  takes drawer space. Tiny toggles (shuffle/repeat/sleep) may stay on the
  transport bar.
- Drawer skeleton BUILT in b26 with #10 (Library live, Utilities = sleep
  timer, Effects awaits #16/#17/#19).
