DONE detail for #15 (b30): vendored libFLAC + libogg (both BSD/Xiph, matches the
project's permissive-only policy) under vendored/flac + vendored/ogg. New
DEC_KIND_OGGFLAC in vendored/decoders/decoders.c; an Ogg FLAC file is now
decoded by libFLAC through the existing pcm_to_stereo path, so it gets the same
resampler/SEEK/END_OF_STREAM behaviour as WavPack and can play alongside Ogg
Vorbis in one queue. Fixtures: tools/fixtures/*.oga (8/16/24/32-bit, mono,
stereo, 5ch, 22.05/44.1/96 kHz) plus reference .oga files from the reference
`flac` CLI for cross-verification.

DONE detail for #16 (b31): Effects drawer tab with a 64-band log-spaced
spectrum, peak-hold caps, dBFS readout and decade axis labels. Hand-rolled
radix-2 FFT (src/Spectrum.swift) after vDSP's split-complex real FFT packing was
found to halve bin numbering; DSP split into a testable SpectrumCore.
tools/test_spectrum/main.swift compiles the production source and passes 52
checks (FFT vs naive DFT, tone->bin at 44.1/48/96 kHz, band mapping, level
scaling, ring wrap, stereo downmix). Found and fixed 3 real bugs: Float->Double
ring read after wrap, unnormalized magnitudes, and a -6 dBFS ceiling that
clipped ordinary material.

ARCHIVED — LICENSING UNCLEAR (removed from active goals 2026-09-28; do not
pursue without a clean, redistributable licence that fits the project policy of
permissive-only (MIT/Apache/BSD/MPL) dependencies):
  8. (F) TTA (True Audio)   — no small libtta with a verifiable modern licence.
     The maintained libtta (TTA-Lib) is LGPL-2.1-or-later, and the "BSD" TTA
     Hardware Players Library 1.2 is only available from an old/mirrored
     download whose own text contradicts itself on redistribution terms. Not
     worth shipping ambiguous provenance for one niche format. Revisit only if
     upstream publishes a permissive decoder.

UI / DRAWER DESIGN (agreed 2026-09-23, clean-UX principle):
- Main window must NOT grow crowded. Heavy/optional features live in ONE
  right-side OVERLAY drawer (Xcode/Inspector style - floats over the right
  pane, panes never reflow) with a segmented TAB BAR inside; each tab
  scrolls internally; one toggle opens/closes it.
- Proposed tabs: Library (playlists, format info), Effects (EQ, ReplayGain,
  visualizer), Utilities (sleep timer, metadata editor).
- Mini player = separate floating window; media keys = global; neither
  takes drawer space. Tiny toggles (shuffle/repeat/sleep) may stay on the
  transport bar.
- Drawer skeleton BUILT in b26 with #10 (Library live, Utilities = sleep
  timer, Effects awaits #16/#17/#19).
